# MAPDOME

**WHO KNOWS THE EARTH THE BEST**

A geography party game for solo practice and online rooms of 2–8 players. Choose Location, City, or Country mode, then compete across 5, 8, or 10 rounds with a configurable timer. Guesses stay hidden until the round reveal; the live leaderboard updates scores and names a match winner.

## Hosting

The public site is served from `index.html` on the `main` branch through GitHub Pages.

## Game services

MAPDOME uses PeerJS for room signaling, OpenStreetMap for guess maps, and MapillaryJS and the Mapillary Graph API for street imagery. The host and players keep their browsers open during a match. Street imagery depends on Mapillary coverage.
